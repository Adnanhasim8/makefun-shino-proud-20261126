# Make the AI Judge Feel Proud: A Family Scene

One short family scene — a small, warm, funny domestic moment in a single line. Every morning, Dad still cuts the crusts off my sandwiches, and the narrator is twenty-six: one concrete ritual, no explanation, the affection left unsaid.

## How to run

```sh
python3 main.py
```

This writes the scene to `/output/entry.txt`. To write elsewhere, use `python3 main.py --out <path>` or set `MAKEFUN_OUTPUT_DIR`. Python 3.13 standard library only; no network at run time.
